# Basic C# Programs for Pitman Training – Part Two

This repository contains a collection of C# programs and exercises completed as part of Pitman Training Part Two. It is focused on reinforcing core programming concepts through practical assignments and small console applications.

## Overview

Each folder in this repository demonstrates a different topic in C# and object-oriented programming. The projects cover a range of beginner-to-intermediate concepts, including variables, loops, arrays, lists, methods, classes, inheritance, polymorphism, abstraction, and exception handling.

## Repository contents

- Abstract Class Assignment — exercises involving abstract classes and inheritance
- ArraysAndLists — working with arrays and lists in C#
- Blackjack — a simple console-based blackjack game
- Calling_Methods_Assignment_Math_Operations — method calls and arithmetic operations
- Class Method Assignment — class structure and method design
- Console_App_Strings_and_Integers_Assignment — string and integer manipulation in a console app
- Default_Value_Assignment — default values and variable initialization
- Exception_Handling_Tutorial — try/catch/finally examples and error handling
- Iteration_Lesson — loops and iterative programming concepts
- List_and_iteration_practice_assignment — practical practice using lists and iteration
- Method_Class_Assignment_Submission — methods within classes and object-oriented structure
- Method_Overload_Math_Assignment — overloaded methods and calculation logic
- Polymorphism_Assignment — method overriding and polymorphic behavior
- methods_and_objects_assignment — exercises involving methods and objects

## Topics covered

- C# fundamentals
- Variables and data types
- Arrays and lists
- Loops and iteration
- Methods and method overloading
- Classes and objects
- Inheritance and abstraction
- Polymorphism
- Exception handling
- Console application development

## How to use this repository

1. Open a project folder in Visual Studio or VS Code.
2. Review the code and comments to understand the task or concept.
3. Run the project or application to see the output.
4. Use the code as a learning reference for similar C# exercises.

## Purpose

This repository is intended for learning, practice, and revision. It acts as a record of C# programming exercises completed during training and can be used as a reference for understanding the building blocks of software development in C#.
